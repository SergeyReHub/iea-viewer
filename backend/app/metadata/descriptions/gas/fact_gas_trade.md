# Торговля газом по партнерам

Источник: `iea-data-structure/domain/gas/03_data_description.md`

## Для чего нужен набор
Позволяет анализировать внешнюю торговлю газом по маршрутам и партнерским странам.

## Что можно анализировать
- импорт и экспорт по направлениям;
- динамику торговых потоков по годам и месяцам;
- ключевых партнеров для каждой страны.

## Какие разрезы доступны
- страна-репортер;
- страна-партнер;
- поток (импорт/экспорт);
- продукт;
- период;
- единица измерения.
