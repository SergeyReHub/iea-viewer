# Баланс природного газа

Источник: `iea-data-structure/domain/gas/03_data_description.md`

## Для чего нужен набор
Базовый набор для аналитики природного газа: производство, импорт, экспорт, трансформация и конечное потребление.

## Что можно анализировать
- структуру газового баланса по странам;
- изменение потоков во времени;
- спрос по секторам и трансформационным процессам.

## Какие разрезы доступны
- страна;
- продукт;
- поток баланса;
- периодичность;
- единица измерения.
