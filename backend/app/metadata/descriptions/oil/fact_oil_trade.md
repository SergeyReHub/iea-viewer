# Торговля нефтью по партнерам

Источник: `iea-data-structure/domain/oil/03_data_description.md`

## Для чего нужен набор
Позволяет анализировать внешнюю торговлю нефтью и нефтепродуктами по направлениям «страна-репортер -> страна-партнер».

## Что можно анализировать
- импорт и экспорт по странам-партнерам;
- торговую структуру по продуктам;
- изменение торговых потоков по годам и месяцам;
- концентрацию торговли на ключевых партнерах.

## Какие разрезы доступны
- страна-репортер;
- страна-партнер;
- поток (импорт/экспорт);
- продукт;
- период;
- единица измерения.
