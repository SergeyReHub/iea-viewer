# Добыча по месторождениям

Источник: `iea-data-structure/domain/oil/03_data_description.md`

## Для чего нужен набор
Дает максимально детальный уровень нефтяной статистики — добычу по отдельным месторождениям.

## Что можно анализировать
- вклад конкретных месторождений в добычу страны;
- динамику добычи по типу месторождения;
- различия между onshore и offshore сегментами.

## Какие разрезы доступны
- месторождение и его группа;
- страна;
- продукт;
- среда добычи;
- период и периодичность.
