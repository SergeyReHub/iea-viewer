# Единицы измерения

Источник: `iea-data-structure/domain/base/data_description.md`

## Для чего нужен
Справочник объясняет, в каких единицах представлены значения в таблицах (объем, энергия, масса и т.д.).

## Что увидит пользователь
- код и название единицы;
- краткое обозначение;
- тип единицы (например, энергия, объем, масса).

## Примеры
- `TJ` — тераджоуль;
- `M_M3` / `M3` — объем газа;
- `KT` — тысячи тонн;
- `KBD` — тыс. баррелей в сутки.
