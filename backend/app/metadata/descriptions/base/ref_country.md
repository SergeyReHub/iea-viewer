# Страны и регионы

Источник: `iea-data-structure/domain/base/data_description.md`

## Для чего нужен
Этот справочник задает географию для всех отчетов: отдельные страны, региональные группы и агрегаты.

## Что увидит пользователь
- международный код страны;
- название на русском и английском;
- принадлежность к группе (например, OECD, ЕС, G20);
- иерархию «страна -> регион -> агрегат».

## Как использовать в аналитике
- отбирать конкретные страны или целые регионы в фильтрах;
- строить сравнение «страна vs регион»;
- быстро находить объединения вроде OECD/Non-OECD.
