# Источники данных

Источник: `iea-data-structure/domain/base/data_description.md`

## Для чего нужен
Справочник показывает, из какого официального набора IEA пришла каждая запись.

## Что увидит пользователь
- код источника;
- понятное название набора;
- домен (oil, gas и др.).

## Примеры источников
- `SUPPLY` — поставки и баланс в нефтяном домене;
- `BALDAT` — баланс природного газа;
- другие специализированные наборы для разных тематик.
