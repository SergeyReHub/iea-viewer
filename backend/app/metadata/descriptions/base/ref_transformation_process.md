# Процессы трансформации энергии

Источник: `iea-data-structure/domain/base/data_description.md`

## Для чего нужен
Справочник описывает, в каких технологических процессах один вид энергии преобразуется в другой.

## Что увидит пользователь
- код и название процесса;
- тип процесса (электроэнергетика, тепло, переработка и т.д.);
- связь с профильными показателями в балансе.

## Примеры
- электростанции и ТЭЦ;
- переработка на НПЗ;
- газовые и коксохимические процессы.
