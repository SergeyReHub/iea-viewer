# Периодичность данных

Источник: `iea-data-structure/domain/base/data_description.md`

## Для чего нужен
Показывает, с какой частотой публикуются данные: год, квартал, месяц и т.д.

## Основные значения
- `A` — ежегодно;
- `Q` — ежеквартально;
- `M` — ежемесячно;
- `W` — еженедельно;
- `D` — ежедневно.

## Как использовать в аналитике
Используйте этот справочник, когда нужно отделить долгосрочные ряды от более детальных (например, месячных).
