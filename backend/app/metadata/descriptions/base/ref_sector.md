# Секторы потребления

Источник: `iea-data-structure/domain/base/data_description.md`

## Для чего нужен
Справочник группирует конечное потребление энергии по секторам экономики.

## Что увидит пользователь
- коды и названия секторов;
- детализацию внутри крупных групп;
- соответствие отраслевой логике (промышленность, транспорт, услуги, население).

## Примеры секторов
- промышленность;
- транспорт;
- жилой и коммерческий сектор;
- сельское хозяйство;
- неэнергетическое использование.
