# Типы электростанций

Источник: `iea-data-structure/domain/electricity/data_description.md`

## Для чего нужен
Справочник задает классификацию типов станций и режимов генерации в электроэнергетике (основные производители, автопроизводители, ТЭЦ, отдельные типы установок).

## Что увидит пользователь
- код типа станции;
- название и русское название;
- категорию типа станции;
- иерархию типов через родительский код.

## Примеры
- `MAINELEC`, `MAINCHP`, `MAINHEAT`;
- `AUTOELEC`, `AUTOCHP`, `AUTOHEAT`;
- агрегаты `MAINTOT`, `AUTOTOT`, `TOTAL`.
