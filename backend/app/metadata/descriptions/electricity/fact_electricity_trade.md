# Импорт/экспорт электроэнергии по партнерам

Источник: `iea-data-structure/domain/electricity/data_description.md`

## Что это за таблица
Факт-таблица внешней торговли электроэнергией с детализацией по стране-отчетчику и стране-партнеру.

## Основные измерения
- `reporter_code` — страна-отчетчик;
- `partner_code` — страна-партнер (направление торговли);
- `product_code` — продукт (в основном `ELECTRICITY`);
- `flow_code` — тип потока (`IMPORTS` / `EXPORTS`);
- `time_period`, `frequency_code`, `unit_code`.

## Что анализировать
- крупнейшие торговые направления по странам-партнерам;
- долгосрочную динамику импорта и экспорта;
- торговый баланс по отдельным странам.
