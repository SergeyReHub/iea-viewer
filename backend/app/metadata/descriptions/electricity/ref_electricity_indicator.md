# Индикаторы электроэнергетики

Источник: `iea-data-structure/domain/electricity/data_description.md`

## Для чего нужен
Справочник определяет набор индикаторов для таблиц генерации и мощности: выработка, вход топлива, установленная мощность и связанные показатели.

## Что увидит пользователь
- код индикатора;
- название и русское название;
- тип индикатора;
- подсказку по ожидаемой единице измерения.

## Примеры
- индикаторы генерации: `GELEPROD`, `NELEPROD`, `GHEATPRO`, `NHEATPRO`;
- индикаторы входа топлива: `INPUTTJ`, `INPUTTON`;
- индикаторы мощности и пиков: `TOTAL`, `PEAKLOAD`, `PEAKCAP`.
