# Квартальная статистика угля

Источник: `iea-data-structure/domain/coal/data_description.md`

## Для чего нужен набор
Квартальный набор для оперативного анализа добычи и торговли углем с детализацией по стране и партнеру.

## Источник в IEA Data Explorer
Набор формируется из квартальных выгрузок Coal Data Explorer (`CST*`), включая торговые ряды.

## Что можно анализировать
- сезонную динамику потоков угля по кварталам;
- квартальные изменения импорта и экспорта;
- сравнение стран по структуре угольного рынка.

## Какие разрезы доступны
- страна;
- страна-партнер;
- продукт;
- поток;
- год и квартал;
- единица измерения.
