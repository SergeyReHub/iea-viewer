# Баланс угля

Источник: `iea-data-structure/domain/coal/data_description.md`

## Для чего нужен набор
Базовый набор для аналитики угольного рынка: добыча, предложение и использование угля по странам и периодам.

## Источник в IEA Data Explorer
Основной набор соответствует квартальному датасету `OECD.IEA:CST(1.0)`.

## Что можно анализировать
- структуру угольного баланса по странам;
- динамику потоков угля во времени;
- спрос по секторам и процессам трансформации.

## Какие разрезы доступны
- страна;
- продукт;
- поток баланса;
- периодичность;
- единица измерения.
