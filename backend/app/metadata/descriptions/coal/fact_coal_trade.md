# Торговля углем по партнерам

Источник: `iea-data-structure/domain/coal/data_description.md`

## Для чего нужен набор
Позволяет анализировать внешнюю торговлю углем по направлениям поставок и странам-партнерам.

## Источник в IEA Data Explorer
Набор агрегирует торговые выгрузки `OECD.IEA:CSTOECDTRADE(1.0)` и `OECD.IEA:CSTWORLDTRADE(1.0)`.

## Что можно анализировать
- импорт и экспорт угля по направлениям;
- динамику торговых потоков по периодам;
- ключевых партнеров для каждой страны.

## Какие разрезы доступны
- страна-репортер;
- страна-партнер;
- поток (импорт/экспорт);
- продукт;
- период;
- единица измерения.
