# NCV угля

Источник: `iea-data-structure/domain/coal/data_description.md`

## Для чего нужен набор
Набор содержит показатели NCV (net calorific value) по угольным продуктам, странам и потокам.

## Источник в IEA Data Explorer
Данные соответствуют секции NCV legacy-наборов Coal Information (например, `IVT_OECDNCV.txt`).

## Что можно анализировать
- динамику калорийности угольных продуктов;
- сравнение NCV между странами и продуктами;
- влияние структуры потоков на итоговые значения.

## Какие разрезы доступны
- страна;
- продукт;
- NCV-поток;
- периодичность;
- единица измерения.
