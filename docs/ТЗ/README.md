## Правила именования

- **Постановка:** `YYMMDDТЗ{КраткоеНазвание}.docx`
- **Замечания:** `YYMMDDЗамечания.docx` или `YYMMDD_NNЗамечания.docx` при нескольких документах в один день
- Несколько файлов в один день: суффикс `_01`, `_02`, …
- Формат: `.docx` (как у заказчика), без промежуточных `.txt` в репозитории

При добавлении нового документа: префикс с датой поступления, запись в [`TASKS.md`](TASKS.md), описание в разделе «По отчётам» после реализации.
